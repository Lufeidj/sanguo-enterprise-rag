# 能达到的功能

## 1. 已实现功能

### 1.1 文档处理
- 读取《三国演义》原始文本
- 识别章节标题（第X回）
- 章节内滑窗切块
- 生成 chunk 摘要（教学版）

### 1.2 向量知识库
- 自动创建 Milvus 集合 `sanguo_chunks`
- 创建向量索引（HNSW）
- 批量写入向量与元数据
- 统计已有数据量

### 1.3 问答服务
- `GET /health` 健康检查
- `POST /ask` 问答接口
- 返回答案 + 引用片段（章节与 chunk）

### 1.4 一键启动
- `python main.py` 自动检查环境
- 集合为空时自动导入文本
- 自动启动 API

## 2. 教学价值

- 覆盖企业级 RAG 的最小可用闭环
- 支持从“玩具 demo”过渡到“工程化结构”
- 可在 Attu 中可视化验证入库与集合状态

## 3. 当前边界

- Embedding 默认使用教学可复现向量（mock）
- 摘要为规则摘要（非 LLM 摘要）
- 未加入混合检索与 reranker

## 4. 可扩展方向

- 接入真实 Embedding 服务（阿里百炼/其他）
- 增加关键词检索（BM25）与混合召回
- 引入 reranker 提升答案准确率
- 增加 GraphRAG（实体关系图）
- 增加评测基准（召回率、准确率、引用可信度）
