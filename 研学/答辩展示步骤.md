# 答辩展示步骤

## 1. 展示目标（开场 30 秒）

一句话说明：
“本项目实现了《三国演义》企业级 RAG 最小闭环：自动入库、向量检索、引用可追溯问答。”

## 2. 环境准备（1 分钟）

1. 确认 Milvus 在运行
2. 打开 Attu（`localhost:8000`）
3. 打开项目目录：
   - `Day10/作业/sanguo-enterprise-rag`

## 3. 一键启动演示（2 分钟）

执行：

```bash
python main.py
```

说明三件事：
- 自动检查/创建集合
- 空集合自动导入《三国演义》
- 自动启动 API

## 4. 可视化验证（2 分钟）

在 Attu 中展示：
- `default` 库下出现 `sanguo_chunks`
- 实体数量增长
- 向量字段与索引状态

## 5. 接口问答演示（3 分钟）

请求 `POST /ask`，示例问题：
- “赤壁之战前孙刘联盟如何形成？”
- “诸葛亮出山的关键背景是什么？”

展示返回：
- `answer`
- `citations`（含章节与片段）

重点强调：可追溯、可解释。

## 6. 架构讲解（2 分钟）

按模块快速过一遍：
- `chunking.py`
- `vector_store.py`
- `pipeline.py`
- `api.py`
- `main.py`

## 7. 对比与价值（1 分钟）

对比“普通 demo”：
- 不是一次性脚本，而是可服务化结构
- 支持自动导入与可视化验证
- 具备后续扩展能力（reranker/GraphRAG/评测）

## 8. 结尾与扩展（30 秒）

后续计划：
- 接真实 embedding
- 引入混合检索 + reranker
- 升级 GraphRAG 处理复杂人物关系
