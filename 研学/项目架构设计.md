# 项目架构设计

## 1. 总体架构

本项目采用典型的企业级 RAG 分层架构：

1. 数据层：原始文档（《三国演义》文本）
2. 处理层：章节切分、滑窗切块、摘要生成（教学版为规则摘要）
3. 索引层：Milvus 向量存储（`sanguo_chunks` 集合）
4. 服务层：FastAPI 提供问答接口
5. 应用层：Attu 可视化、API 调用方（前端/脚本）

## 2. 模块拆分

- `src/config.py`
  - 集中管理环境变量（Milvus、API、模型）
- `src/chunking.py`
  - 文档切块逻辑（章节优先 + 滑窗）
- `src/vector_store.py`
  - Milvus 封装：建表、建索引、插入、检索、统计
- `src/llm.py`
  - Embedding 与回答生成（支持教学模式与真实模型模式）
- `src/pipeline.py`
  - 端到端流程编排（入库、检索、问答、启动引导）
- `src/api.py`
  - Web 服务接口（`/health`、`/ask`）
- `scripts/ingest_sanguo.py`
  - 手动导入脚本
- `main.py`
  - 一键启动入口（自动检查并导入 + 启动 API）

## 3. 数据流

1. 读取《三国演义》文本
2. 按“第X回”切分章节
3. 章节内滑窗切块（保留上下文重叠）
4. 生成向量
5. 写入 Milvus（含元数据）
6. 用户提问 -> 向量检索 -> 组装上下文 -> 生成回答 -> 返回引用

## 4. 企业化设计点

- 配置化：参数通过 `.env` 管理
- 可替换：Embedding/LLM 可替换成真实服务
- 可追溯：返回 `chunk_id`、章节信息、片段内容
- 可扩展：后续可接入 reranker、GraphRAG、权限体系
